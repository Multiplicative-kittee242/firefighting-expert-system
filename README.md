# 🚒 firefighting-expert-system - Learn maritime fire safety through logic

[![Download Application](https://img.shields.io/badge/Download-Application-blue.svg)](https://github.com/Multiplicative-kittee242/firefighting-expert-system)

This expert system helps students understand fire suppression strategy. It uses rule-based logic to simulate firefighting decisions. The program provides guidance on maritime safety procedures during emergency scenarios.

## 📋 What this tool does

This software acts as a virtual coach. It uses a knowledge base to analyze fire conditions. You input details about a fire, such as the location, fuel source, and intensity. The system applies logical rules to suggest the best firefighting techniques. 

The software runs on a Java engine known as CLIPS. This engine makes complex decisions based on facts about the environment. It acts like a digital playbook for fire safety.

## ⚙️ Using the software

The program interface displays several input fields. Complete these steps to run a simulation:

1. Start the application.
2. Observe the main dashboard. It lists available safety scenarios.
3. Select a scenario that matches your interest.
4. Answer the questions regarding the fire incident. Be as accurate as possible with your inputs.
5. Click the "Process" button to allow the rule engine to calculate the result.
6. Review the advice in the results window. The system outlines specific steps to contain the fire based on maritime standards.
7. Click "Reset" to clear the fields and start a new simulation with different variables.

## 🧠 Understanding the logic

The application relies on forward-chaining. In simple terms, this means the system looks at your facts first. It then draws conclusions based on those facts. It behaves like a flowchart that updates in real-time. If you change one variable, the system updates its advice automatically. This demonstrates how symbolic artificial intelligence helps human operators during training.

## 🛠️ Troubleshooting common issues

If the application fails to open, verify that you have Java installed. Open your command prompt, type "java -version," and press Enter. If your system does not recognize this command, visit the Java website.

If the graphical interface looks blurry, check your Windows display settings. Ensure your scaling is set to 100%.

If the application hangs or stops responding, close the window and open it again. This clears the memory of the rule engine.
